# Brierfield Pathway GitHub defaults

This public repository provides default contribution and pull-request guidance for repositories in the **brierfieldpathway** organisation that do not define their own files.

- [CONTRIBUTING.md](CONTRIBUTING.md): shared development expectations.
- [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md): small, practical PR checklist.

The full **Brierfield Labs Coding House Rules** remain authoritative in [brierfieldlabs/infrastructure](https://github.com/brierfieldlabs/infrastructure/blob/main/procedures/coding-house-rules.md) for authorised contributors. The [approved project starter](https://github.com/brierfieldlabs/_template) supplies `AGENTS.md` and `PROJECT.md` for new code repositories when access permits.

GitHub can use these as default community files, but it does **not** automatically inherit `AGENTS.md` from this repository or require new repositories to use a template. Existing repository-specific contribution, approval, safety and release requirements remain in force. Do not put organisation secrets or private Infrastructure details here.
